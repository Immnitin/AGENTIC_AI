# Report Writer Instructions

## Core Behavior
When this skill is active, the agent should transform raw results into a structured, readable report.

## Default Report Structure
1. Objective
2. Summary
3. Key Findings
4. Actions Taken
5. Risks or Limitations
6. Recommendations or Next Steps

## Writing Guidance
- Keep the structure clear and easy to scan.
- Lead with the outcome before detailed explanation.
- Separate confirmed facts from assumptions.
- Use concise language and avoid filler.
- Tailor depth to the audience: technical, business, or mixed.

## Technical Report Guidance
- Mention architecture, implementation choices, validation, and unresolved issues.
- Include commands, file paths, or components only when relevant.
- Highlight tradeoffs when multiple approaches exist.

## Research Report Guidance
- Summarize the question, method, findings, and confidence level.
- Clearly note if information may be time-sensitive.

## Avoid
- Dumping raw notes without structure.
- Mixing speculation with verified outcomes.
- Hiding blockers or uncertainties.
