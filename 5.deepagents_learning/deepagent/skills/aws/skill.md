# AWS Skill

## Purpose
Use this skill when the user asks for AWS architecture, cloud deployment, IAM-aware designs, serverless systems, storage, compute, networking, monitoring, or cost-conscious AWS implementation help.

## When To Activate
- The user mentions AWS services such as Lambda, S3, EC2, ECS, EKS, RDS, DynamoDB, API Gateway, CloudWatch, IAM, or Step Functions.
- The task involves deployment, infrastructure, permissions, observability, or cloud architecture tradeoffs.

## What This Skill Provides
- AWS-specific architecture and implementation guidance.
- Security-first defaults and least-privilege suggestions.
- Practical service selection advice.
- Example contexts for serverless, data, and deployment tasks.

- `example_deployment.md`
