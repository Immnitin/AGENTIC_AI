# Example: Python Data Processing Task

## User Query
Read a CSV of sales records, group by region, and calculate total revenue and average order value.

## How The Skill Should Help
- Use pandas if tabular analysis is appropriate.
- Mention expected columns.
- Handle missing or malformed numeric values.
- Return both code and a short interpretation of the output.

## Response Pattern
1. State assumptions about the CSV schema.
2. Provide the processing code.
3. Explain the aggregation logic.
4. Mention edge cases.
