# Example: AWS Serverless API

## User Query
Design an AWS serverless backend for a to-do application with authentication and audit logging.

## How The Skill Should Help
- Suggest API Gateway, Lambda, DynamoDB, Cognito, and CloudWatch.
- Mention IAM boundaries and structured logs.
- Note tradeoffs for cost and simplicity.
- Include a high-level request flow.

## Response Pattern
1. Summarize the architecture.
2. Explain each service role.
3. Highlight security and logging.
