# Report Writer Skill

## Purpose
Use this skill whenever DeepAgent must produce a polished report-style answer, post-task summary, research brief, implementation report, or executive-readable explanation.

## When To Activate
- The user explicitly asks for a report, summary, documentation, or write-up.
- The agent completes a complex task and needs to present a structured final answer.
- The system wants a consistent answer format for important outputs.

## What This Skill Provides
- A reporting structure for clear, professional responses.
- Guidance for organizing findings, decisions, risks, and next steps.
- Example report patterns for technical and research outputs.

## Companion Context Files
- `instruction.md`
- `example_technical_report.md`
- `example_research_report.md`
- `example_status_report.md`

## Retrieval Hint
Load this skill near the end of execution when preparing the final response, unless the user asks for the report format at the start.
