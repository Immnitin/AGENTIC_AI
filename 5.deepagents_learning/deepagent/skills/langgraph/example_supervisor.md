# Example: LangGraph Supervisor

## User Query
Build a supervisor graph that delegates tasks to a research agent and a coding agent.

## How The Skill Should Help
- Define supervisor responsibilities separately from worker roles.
- Track task assignments and outputs in state.
- Add a synthesis node that merges worker results.
- Ensure a clear completion condition.

## Response Pattern
1. Explain supervisor and worker roles.
2. Show the graph design.
3. Provide implementation details.
