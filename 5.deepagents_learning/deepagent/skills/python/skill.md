# Python Skill

## Purpose
Use this skill when the user asks for Python code, Python debugging, scripting, automation, APIs, data processing, notebooks, testing, or backend logic in Python.

## When To Activate
- The user explicitly asks for Python.
- The task involves `.py` files, Jupyter notebooks, FastAPI, Flask, Django, pandas, NumPy, or automation scripts.
- The agent needs executable examples, clean Python architecture, or debugging help.

## What This Skill Provides
- Python-specific implementation guidance.
- Best practices for readability, modularity, typing, and error handling.
- Common patterns for APIs, scripts, data pipelines, and tests.
- Example prompts and response patterns stored in companion files.

## Companion Context Files
- `instruction.md`
- `example_api.md`
- `example_data_processing.md`
- `example_debugging.md`

## Retrieval Hint
When this skill is activated, prioritize loading `instruction.md` first, then load only the example file most relevant to the task.
