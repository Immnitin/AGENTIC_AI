# Example: AWS Deployment Task

## User Query
How should I deploy a Python API on AWS with CI/CD and environment separation?

## How The Skill Should Help
- Distinguish between serverless and container deployment options.
- Suggest staging and production separation.
- Include secrets handling and rollback strategy.
- Mention CI/CD options such as GitHub Actions or AWS-native tooling.

## Response Pattern
1. Present the recommended deployment path.
2. Explain environment strategy.
3. Mention release safety practices.
