# Example: Python API Task

## User Query
Build a small FastAPI endpoint that accepts a product name and returns a generated SKU.

## How The Skill Should Help
- Choose FastAPI for concise API development.
- Create a request model and response model.
- Validate empty names.
- Return a deterministic SKU format.

## Response Pattern
1. Briefly explain the endpoint design.
2. Provide the Python code.
3. Mention how to install dependencies.
4. Show how to run the app.
