# Example: Python Debugging Task

## User Query
My Python script crashes with `KeyError: user_id` when parsing API data.

## How The Skill Should Help
- Explain why the key may be missing.
- Suggest safe access patterns such as `.get()` or schema validation.
- Show a corrected version.
- Recommend lightweight logging for diagnosis.

## Response Pattern
1. Identify likely root causes.
2. Show the minimal fix.
3. Suggest a more robust long-term approach.
